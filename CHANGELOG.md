- DM-004–006. FastAPI получил liveness и readiness, настройки и JSON-логи с Request ID. Compose объединяет приложения, PostgreSQL с pgvector и n8n.
- DM-007. Асинхронные SQLAlchemy-сессии, реальная проверка БД и миграция Alembic `0001`. Отдельный тестовый кластер проверяет транзакции и восстановление.

- DM-010. GitHub Actions проверяет репозиторий, backend, БД, frontend, n8n и Docker, собирает отчёты и вычисляет CI Gate.
- DM-011. Добавлены правила разработки, справочники API и настроек, концептуальная модель данных, сценарии демонстрации и runbook.
- DM-012. Технически принят фундамент на `382730c` после запуска из GitHub, проверки восьми сценариев, сохранности данных и CI Gate. Добавлены доказательства, реестр дефектов и инструкции для независимого ревью. [Отчёт](docs/acceptance/PHASE_0_ACCEPTANCE.md)
- DM-101. Определены восемь CRM-сущностей, правила движения и закрытия сделки, история этапов, валюты и источники данных для аналитики и риска. [Модель](docs/DATA_MODEL.md) · [ADR-0004](docs/adr/0004-crm-domain-model.md)
- DM-102. Реализованы восемь типизированных CRM-моделей, ревизия `0002`, ограничения организации, воронки и коммерческих данных. Проверены миграции и прямые записи в PostgreSQL. [Приёмка](docs/tasks/DM-102.md)
- DM-103. Добавлены воспроизводимый генератор 800 CRM-сделок, 34 контрольных сценария и транзакционный CLI-загрузчик с проверкой повторного запуска. [Manifest](data/demo/dataset-manifest.json) · [Приёмка](docs/tasks/DM-103.md)
