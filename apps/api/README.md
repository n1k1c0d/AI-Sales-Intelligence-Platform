# DealMind · FastAPI Backend

Python-приложение будет принимать REST-запросы от веб-интерфейса и интеграций. Backend владеет доменными записями в PostgreSQL, проверяет доступ к данным организации и разрешение на внешнее действие. Здесь будут рассчитываться KPI воронки и оценки Risk Engine, собираться контекст сделки и выполняться AI-сценарии. [Границы модулей и потоки данных](../../docs/ARCHITECTURE.md)

## Организация кода

Ниже показано планируемое расположение кода. Сейчас в репозитории зарезервированы корень пакета и каталоги тестов.

```text
apps/api/
├── src/dealmind/
│   ├── api/            # HTTP-маршруты и зависимости FastAPI
│   ├── core/           # Конфигурация и логирование
│   ├── db/             # Подключения и сессии SQLAlchemy
│   ├── models/         # Модели хранения
│   ├── schemas/        # Контракты запросов и ответов Pydantic
│   ├── repositories/   # Чтение и запись данных организации
│   ├── services/       # Прикладные сценарии и транзакции
│   ├── analytics/      # Правила расчёта KPI
│   ├── risk/           # Версионированные правила риска
│   ├── ai/             # LangGraph, RAG и интерфейсы провайдеров
│   └── integrations/   # Адаптеры внешних систем
├── tests/              # Unit и integration tests
├── alembic/            # Миграции схемы PostgreSQL
├── pyproject.toml
└── Dockerfile
```

Routes будут валидировать вход и вызывать прикладной сервис. Доменные правила принимают факты и опорное время явно, поэтому их можно проверить без HTTP и БД. Repositories отвечают за запросы через SQLAlchemy и Psycopg 3. LangGraph получит ограниченные инструменты доступа к данным, а RAG будет использовать документы и pgvector.
