# DealMind · Web UI

Веб-интерфейс предназначен для менеджера и руководителя отдела продаж. Next.js, React и TypeScript будут отвечать за экраны и взаимодействие с FastAPI через версионированный REST API. Tailwind CSS и shadcn/ui используются в планируемых компонентах, Recharts — для графиков воронки. [Архитектура и границы API](../../docs/ARCHITECTURE.md)

Пользователь сможет перейти от показателя воронки к списку сделок, открыть карточку, увидеть причины риска и проверить источники AI-рекомендации. Через интерфейс RAG можно будет задать вопрос по документам школы. При согласовании UI передаст решение пользователя по конкретной версии действия. Расчёт KPI, проверка прав и разрешение на исполнение остаются в backend.

В **DM-008** появится первая страница со статусом доступности API и обработкой ошибки подключения. Дашборд и рабочие экраны относятся к PHASE 5. Сейчас каталог содержит только документацию и заготовку пути для страниц. [Roadmap](../../docs/ROADMAP.md)
