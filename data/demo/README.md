# DealMind · Демонстрационные данные

Здесь будут храниться синтетические данные онлайн-школы для проверки воронки и рисков. Набор свяжет вымышленных менеджеров и клиентов со сделками, этапами, касаниями, переходами и причинами потерь. Для сценариев RAG добавятся демонстрационные документы о курсах.

В **DM-103** генератор получит параметры random seed и опорной даты в UTC. Их сочетание должно воспроизводить идентификаторы, суммы и историю событий, включая открытую сделку без своевременного касания. Повторный импорт того же набора должен сохранять количество записей и связи между ними. [План генерации и приёмка](../../docs/ROADMAP.md)

Для табличных данных допустим CSV, для связанных записей и событий — JSON или JSONL, для текстовых источников — Markdown. Данные создаются с нуля. Выгрузки production CRM, реальные имена клиентов, телефоны, email и переписка в демонстрационный каталог не допускаются. Для локальных выгрузок правила Git исключают `data/exports/`, для дампов, включая обычный SQL, — `data/dumps/`. Наборы данных появятся в PHASE 1 и последующих этапах.
