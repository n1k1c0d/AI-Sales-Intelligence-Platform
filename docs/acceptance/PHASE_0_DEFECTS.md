### FND-DEF-001 · P2 · Установка uv на Windows · Исправлено в документации

В чистом клоне выполните `uv sync --locked` в `apps/api`. При несовместимых жёстких ссылках Windows прервала установку alembic с `os error 396`. Ожидалась установка всех версий из lockfile. Ошибка зависит от файловой системы и расположения кеша. В [RUNBOOK](../RUNBOOK.md) добавлен `uv sync --locked --link-mode copy`. Регрессия пройдена в отдельной новой виртуальной среде: установлены 43 пакета, импорт выдал `DealMind API`. Эти же версии прошли backend и database suites.

### FND-DEF-002 · P2 · Локальный запуск API на Windows · Исправлено в документации

В `apps/api` Windows-инструкция явно выбирает selector loop, а общий runbook опускал этот параметр. На несовместимом стандартном цикле событий Windows диагностический запрос через TestClient вернул HTTP 500 / `InterfaceError` до проверки пароля Psycopg. Ожидаемая реакция для доступной БД — 200, для неверного пароля — 503. В runbook добавлена ссылка на [штатную команду API](../../apps/api/README.md). При повторе через реальный Uvicorn с `--loop asyncio:SelectorEventLoop` получены 200 и 503 соответственно. Исправление касается запуска на хосте. [Результаты `negativeConfiguration`](evidence.json)

### FND-DEF-003 · P3 · Язык приёмки UI · Открыто

Откройте [System Overview](assets/operational-1440.png) и проверьте три состояния через [панель статуса](../../apps/web/src/features/system-status/panel.tsx). ТЗ одновременно запрашивает проверку русских подписей и сохранение текущего языка. Реализованный UI выводит `All systems operational`, `System degraded` и `Backend unavailable`. Диагностические значения корректны. Проверены английские подписи и текущий дизайн. Перевод требует отдельного решения владельца. Проверку локализации можно добавить при утверждении русского интерфейса.

### FND-DEF-004 · P3 · Тестовый клиент Python · Открыто

Запустите backend pytest с действующим lockfile. Все тесты проходят, но Starlette выводит `StarletteDeprecationWarning` о применении httpx с TestClient. Предупреждение поступает из зависимости, на обработку production HTTP в этом прогоне не повлияло. При плановом обновлении проверьте поддержку транспорта и повторите [ASGI suite](../../apps/api/tests/integration/) и database suite.

### FND-DEF-005 · P3 · ESLint · Открыто

При `npm ci` npm сообщает о завершении поддержки `eslint@9.39.5`. Ожидается поддерживаемый lint toolchain. Установка и `npm run lint` прошли, реестр npm сообщил ноль известных уязвимостей. Запланируйте совместимое обновление с проверкой [конфигурации](../../apps/web/eslint.config.mjs), Next.js, typecheck, тестов и build.

## Наблюдения, влияющие на повтор проверки

Повторный CLI-импорт переносимого JSON в тот же n8n присваивает второй ID. Проверка количества «ровно один», подходящая для свежего импорта, при этом закономерно завершилась ошибкой. Сверка списка подтвердила наличие исходного и нового ID, как и описано в [процедуре импорта](../../automations/n8n/workflows/system-health-check.md).

Техническая приёмка относится к локальному контуру. Для публичного развёртывания остаются прикладная аутентификация, авторизация и RBAC, HTTPS, rate limiting, эксплуатация секретов, hardening и проверенное восстановление из резервных копий. Сверка архитектуры с тремя ADR описана в [отчёте](PHASE_0_ACCEPTANCE.md).
