# DealMind · Roadmap

Roadmap описывает путь от каркаса репозитория до демонстрации сделки с высоким риском. Строка задачи определяет результат, прямые зависимости и проверку приёмки. Порядок разделов задаёт очерёдность этапов. Внутри этапа независимые задачи могут выполняться после своих зависимостей. Отдельное ТЗ уточняет детали перед реализацией.

**Статусы.** BACKLOG — запланировано, READY — можно начинать, IN_PROGRESS — ведётся работа, BLOCKED — есть препятствие, DONE — критерии проверены.

**Приоритеты.** P0 — необходим для фундамента или целостности данных и операций, P1 — основной результат этапа, P2 — оформление или расширение. Номер задачи сохраняется при уточнении приоритета или зависимостей.

**Текущая позиция.** PHASE 0 — TECHNICALLY ACCEPTED. DM-001…DM-012 — DONE. Исправления DM-012.1 прошли [CI на eaa635a](https://github.com/n1k1c0d/AI-Sales-Intelligence-Platform/actions/runs/45692305209). В PHASE 1 DM-101 и DM-102 — DONE, DM-103 — READY. [Физическая модель](DATA_MODEL.md) · [Проверки DM-102](tasks/DM-102.md) · [Внешнее ревью](acceptance/PHASE_0_EXTERNAL_REVIEW.md). [Протокол DM-012](acceptance/PHASE_0_ACCEPTANCE.md)
