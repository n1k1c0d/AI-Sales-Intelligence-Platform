## Acceptance Environment

Чистый удалённый клон, Windows, локальные Docker Linux containers. Проект `dealmind-acceptance-b79724bc3` имел собственные сеть, тома, четыре порта на loopback и сгенерированные тестовые секреты. Owner основного n8n и рабочая БД не использовались.

## Verification Strategy

Для каждого сервиса проверены внешний контракт и наблюдаемое поведение потребителей. Остановки выполнялись после сверки project labels, mounts и идентичности БД. Транзакции проверены на реальном PostgreSQL отдельного проекта DM-007. Для UI использовался Edge, для n8n — ручной запуск через штатный CLI и сверка Request IDs с логами FastAPI.

## Definition of Done

Для принятия требовались чистый checkout, воспроизводимые зависимости, работа четырёх сервисов, миграция, реальные UI и n8n, проверенные отказ, восстановление и сохранность, успешный CI для проверяемого SHA и отсутствие открытых P0/P1. Проверка завершилась с вердиктом **ACCEPTED**. Публикация отчёта и решение внешнего ревьюера остаются отдельными шагами владельца.

## Actual Results

Выполнены 8/8 E2E, 65 backend, 4 database, 29 frontend и 9 validator tests. В PostgreSQL сохранились контрольное значение и ревизия `0001`, в n8n — workflow и история. Прошли все семь заданий удалённого CI для baseline. Рабочие изменения DM-012 проверяются локально до их публикации в `dev`.
