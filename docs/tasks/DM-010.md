## 2. CI Architecture

`DealMind CI` использует GitHub-hosted `ubuntu-24.04`. События — push в `dev` или `main`, обычный PR в `main` и `workflow_dispatch`. Default branch подтверждена по Git remote. Группа concurrency включает имя workflow и Git ref, устаревшие запуски одной ссылки отменяются. Первые шесть jobs независимы. Gate с условием `always()` получает их результаты и требует шесть значений `success`.

| Job | Timeout | Проверка |
| --- | --- | --- |
| repository-checks | 5 мин | Структура, ссылки, Git hygiene, Compose и actionlint |
| backend-quality | 10 мин | Locked install, Ruff, Mypy, pytest, coverage, wheel/sdist |
| database-integration | 15 мин | Реальная изолированная PostgreSQL, DM-007, обязательные JUnit cases |
| frontend-quality | 15 мин | Чистая установка, lint, типы, Vitest, сборка без доступного API |
| n8n-validation | 15 мин | Валидатор, негативные fixtures, импорт, исполнение и проверка результата |
| docker-smoke | 25 мин | Сборка двух образов, миграция и проверка четырёх сервисов |
| CI Gate | 3 мин | Итог всех обязательных jobs |

Кеш uv привязан к `apps/api/uv.lock`, npm — к `apps/web/package-lock.json`. При промахе выполняется обычная установка. [Workflow](../../.github/workflows/ci.yml)

## 14. Security Review

Токен имеет только `contents: read`, checkout использует `persist-credentials: false`, код PR выполняется на одноразовом runner. CI не требует GitHub Secrets, внешней CRM, OpenAI или ключа пользовательского n8n. Секреты тестового Compose генерируются изолированно, файл окружения удаляется после прогона. Пароль fixture DM-007 предназначен только для её тестовой базы.

На реальных томах тестовых проектов сверяются имена и метки владельца. Cleanup выполняется в `finally` и отдельным шагом `always()` в CI. При локальном повторе создаётся новый проект. Контейнеры и сеть тестового запуска удаляются. Локальные тестовые тома и теги образов сохраняются. В artifacts входят только JUnit, coverage и проверенные JSON. Сырые node executions, Docker inspect, SQLite и env-файлы в список загрузки не входят. [Топология](../../infra/docker/README.md)

## 15. Known Limitations

Удалённый runner и наличие артефактов подтверждены. Повторное попадание в кеш отдельно не измерялось. Права на branch protection и тариф репозитория здесь не проверялись. Правило для `CI Gate` может включить владелец после появления статуса. Сохранены существующие предупреждения о связке Starlette TestClient/httpx и устаревшей ветке ESLint 9 при установке. Для негативных HTTP-ответов используется синтетическая служба. Полная fresh-clone приёмка относится к DM-012. [Как выбрать required check](../ARCHITECTURE.md)
