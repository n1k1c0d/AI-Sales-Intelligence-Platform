## 4. Frontend Architecture и Configuration

Root Layout, заголовок и статические части страницы — Server Components. Клиентская часть выполняет same-origin GET при загрузке и ручном обновлении. Route Handler динамически читает настройки, параллельно запрашивает два постоянных API-пути и независимо разбирает результаты через Zod. Часы и длительности измеряются на сервере. В браузере публичный снимок также проходит runtime-валидацию.

В Docker `API_BASE_URL=http://api:8000`. Локально используется опубликованный порт FastAPI, в проверенном окружении — 8001. Таймаут по умолчанию 8000 мс с диапазоном 1…60000. В upstream-запросах отключены кэширование и следование перенаправлениям. PostgreSQL проверяет FastAPI с помощью SQL. Подробности конфигурации и альтернативы зафиксированы отдельно. [Frontend README](../../apps/web/README.md) · [ADR-0003](../adr/0003-frontend-api-integration.md)

## 5. UI Implementation

Root Layout задаёт язык en, metadata, skip link и шапку с версией из package.json. Четыре карточки показывают Backend API, PostgreSQL, System Readiness и Web Application. Диагностика содержит два пути, коды ответа, время, длительности и полные UUID. Панель сведений о проекте обозначает подготовленную инфраструктуру n8n.

До первого снимка карточки показывают Checking. При обновлении кнопка блокируется до завершения запроса, предыдущая проверка сохраняет своё время. При сбое диагностического маршрута доступны понятное сообщение и повторная попытка. Отказ backend и недоступность PostgreSQL имеют различные текстовые состояния. Размеры экрана, видимый фокус и обновление клавишей Enter проверены в Edge.

## 12. Security Review

Dockerfile фиксирует Node slim по тегу и digest, запускает standalone от пользователя node (UID 1000). Web не имеет mounts и получает только origin и timeout из настроек проекта. В сборку попадают только пути из allowlist `.dockerignore`. Браузерные ресурсы загружаются с одного origin. Проверены 709247 байт клиентского JS в конечном контейнере на внутренний origin, имена секретных параметров, префикс DSN и фактические значения двух локальных секретов. Совпадений нет. Значения исключены из отчёта.

## 15. Known Limitations

Диагностика отражает момент ручной проверки. Она не хранит историю и не измеряет SLA. PostgreSQL видна через readiness FastAPI. Для CI, аутентификации, публичного доступа и бизнес-автоматизаций запланированы самостоятельные этапы.

Установка предупреждает об окончании поддержки ESLint 9.39.5. Эта ветка совместима с peer-диапазоном eslint-plugin-react в официальном наборе Next.js. TypeScript 6.0.3 выбран с учётом диапазона typescript-eslint. Обновление инструментов требует повторной проверки совместимости. Backend-регрессия вывела одно предупреждение Starlette, см. §9.
