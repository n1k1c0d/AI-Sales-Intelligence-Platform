# DealMind · Локальная Docker-инфраструктура

Основной `docker-compose.yml` запланирован в корне репозитория. В этом каталоге будут размещаться дополнительные файлы, на которые ссылается Compose, например настройки инициализации PostgreSQL, когда они понадобятся.

В **DM-005** описывается локальная топология из четырёх сервисов. Next.js показывает данные FastAPI, backend подключается к PostgreSQL с pgvector, а self-hosted n8n обращается к backend по HTTP. Данные PostgreSQL и состояние n8n должны переживать пересоздание контейнеров в постоянных томах. [Топология развёртывания](../../docs/ARCHITECTURE.md)

Секреты передаются локально через окружение или хранилище секретов. В Git допустимы только обезличенные примеры конфигурации. Проверенные команды запуска, проверки готовности и остановки появятся по мере настройки окружения. [Roadmap](../../docs/ROADMAP.md)
